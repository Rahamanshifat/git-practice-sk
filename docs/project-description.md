# Project Description

## Overview

This project is a practical exercise for learning Git and GitHub.

The project contains a simple Python calculator and demonstrates
basic version control workflows.

## Features

- Display student name
- Display today's date
- Add two numbers
- Subtract two numbers
- Multiply two numbers
- Divide two numbers with zero-division error handling

## Git Concepts Practiced

- Repository initialization
- Staging files
- Commits
- Branch creation
- Branch merging
- Remote repositories
- Pushing code to GitHub
